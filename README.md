# AI SSAG Kit

**Security · Safety · Governance** starter materials for agentic AI in SME environments.

This repo is a public proof shelf: practical control artefacts you can read in minutes — not a product pitch and not legal advice.

Maintained by [Tony Whelan](https://github.com/anwhelan01) · AI SSAG Architect · Liverpool, UK · `tonywhelan.ai@gmail.com`

## Why this exists

AI is moving from question-and-answer tools to systems that **plan, use tools, and act**. That creates leverage and new failure modes. SMEs want the upside; buyers and regulators still expect accountable controls over access, authority, escalation, and evidence.

SSAG is the working frame:

| Pillar | Question it answers |
| --- | --- |
| **Security** | What can the system see and change? |
| **Safety** | When must a human take over? |
| **Governance** | Who owns policy, evidence, and review? |

## How to use

1. Start with the **control checklist** for any pilot that can take actions.
2. Fill the **escalation matrix** with real owners (not “the AI team”).
3. Use the **ISMS bridge** when talking to security leads who already speak 27001.
